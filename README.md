# João Pedro Elias da Silva
### Applied Mathematics → Machine Learning & AI Engineering

I am an undergraduate student in **Applied Mathematics and Scientific Computing at ICMC, University of São Paulo (USP)**, building a path into machine learning and AI engineering.

My focus is connecting mathematical reasoning with Python implementations, careful evaluation, and reproducible experiments.

## Focus

- **Foundations:** linear algebra, probability, statistics, and optimization applied to machine learning.
- **Practice:** Python, data preparation, exploratory analysis, and model evaluation.
- **Learning direction:** classical ML → deep learning with PyTorch → Transformers → LLM applications, retrieval, and agents.

These are learning priorities, not a claim of completed projects or professional experience.
