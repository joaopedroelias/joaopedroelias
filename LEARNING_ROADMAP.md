# Learning Roadmap

This is a proposed progression for João Pedro Elias da Silva's ML and AI engineering studies. It does not certify completion, specify a verified weekly schedule, or represent professional experience.

| Stage | Planned learning | Evidence to publish |
| --- | --- | --- |
| Mathematical and Python foundations | Linear algebra, probability, statistics, optimization, NumPy | Explained derivations, small implementations, numerical checks |
| Data preparation and classical ML | pandas, exploratory analysis, baselines, validation | Reproducible analysis, documented sources, leakage-safe splits and error analysis |
| Deep learning | PyTorch, training loops, regularization | Training configuration, learning curves, comparison against a baseline |
| Transformers | Attention, tokenization, sequence modeling | Small implementation, correctness checks, compute and data limitations |
| LLM applications | Embeddings, retrieval, RAG, evaluation | Cited data sources, evaluation set, retrieval and answer-quality analysis, cost and latency |
| Agents and delivery | Tool use, failure handling, deployment | Bounded task, traces, tests for failures, reproducible setup |

## Definition of a portfolio project

Before featuring a project, document:

1. Problem, intended use, and scope.
2. Your contribution and any tutorial or upstream sources.
3. Data provenance, usage terms, and limitations.
4. Installation and exact reproduction steps.
5. Baseline and evaluation method, with reported results tied to saved evidence.
6. Failure cases and next improvements.

Keep study exercises together. Create a separate repository when an original project has enough substance to stand on its own. Record progress with links to actual artifacts rather than pre-filled completion badges.
